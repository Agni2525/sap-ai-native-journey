## Working with AI assistants — three rules

1. **Struggle first.** Minimum 15 minutes stuck before asking. If I can't
   state precisely what I'm stuck on, I haven't tried long enough to ask
   a good question.
2. **Ask for understanding, not answers.** "Explain why this works,"
   "name one improvement," "what would break this at scale" — never
   "write this for me." Test: could I rebuild this from an empty file
   tomorrow? If not, I borrowed it, I didn't learn it.
3. **Log it.** Every prompt that actually worked, every pattern learned,
   every time the assistant was confidently wrong goes in `ai-notes.md`.

Never delegated: the data model, debugging I haven't attempted myself,
anything I'd have to explain in an interview, security/auth decisions,
commit messages.
